Ethic Keyboard es un teclado soberano, offline y centrado en la privacidad, diseñado para quienes buscan un método de entrada rápido y limpio sin telemetría ni elementos superfluos.

Basado en Simple Keyboard y AOSP LatinIME bajo GPL-3.0-or-later, Ethic Keyboard incorpora:
* Idioma de interfaz por aplicación independiente del sistema operativo.
* Menú de proyectos integrado con el ecosistema de apps soberanas de IDEH Labs (Ethic Tuner, Ethic Notes, Ethic Compass, Ethic QR Scanner, Ethic APK Guard y Ethic One Call).
* Cero permisos de internet (solo vibración para respuesta háptica), garantizando que las pulsaciones jamás salgan del dispositivo.
* Auditoría de privacidad y compilaciones reproducibles.

Para habilitar el teclado:

* Abre "Ethic Keyboard" desde el lanzador
* Habilita Ethic Keyboard en los ajustes del sistema
* Cambia a Ethic Keyboard desde el método de entrada actual
* Para editar los ajustes, mantén pulsada la coma "," o abre Ajustes del sistema &gt; Idiomas &amp; entrada &gt; Ethic Keyboard.

<b>Características:</b>

* Tamaño reducido (&lt;1MB)
* Altura del teclado ajustable para mayor espacio en pantalla
* Fila de números
* Deslizar sobre espacio para mover el cursor
* Deslizar para borrar
* Colores de tema personalizados
* Permisos mínimos (solo vibración)
* Sin anuncios

<b>Características que no tiene y nunca tendrá:</b>

* Emojis y GIFs
* Corrector ortográfico o registro de diccionario
* Escritura por deslizamiento
* Sincronización en la nube o telemetría

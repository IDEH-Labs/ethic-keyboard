Privacy policy — Ethic Keyboard

Version 1.4 · last updated: October 11, 2026 (translated into English; practices unchanged since September 12, 2026) · Applies to Ethic Keyboard 6.6.6 (org.jpi59.teclado)

Controller and contact

The controller for this version is jpi59 (IDEH Labs), the maintainer identified in the public repository. For privacy questions or issues, use the public issue tracker.

Text and clipboard

A keyboard receives the text, the selection and the information about the active field that Android and the receiving app give it so that the person can type. Ethic Keyboard processes that data in memory during the input session and passes it to the app where the user is typing. It does not store, profile, sell, share or transmit that text to servers of jpi59 or of third parties.

When the user taps paste, it can read the text in the system clipboard only to insert it where the user asked. It does not create a persistent copy and does not transmit it.

Preferences, retention and backups

The app stores language, layout, theme, size and vibration preferences locally. They are not designed to contain typed text. They remain until the user changes them, clears the app's data from Android's Settings or uninstalls it.

Ethic Keyboard turns off its cloud backups and does not request backups. Some manufacturers may keep device-to-device transfers as part of the system migration; that feature depends on the operating system and is not a service of Ethic Keyboard.

Network, permissions and accounts

The app declares no Internet permission and includes no ads, analytics, telemetry, trackers or network services. The only normal permission declared is VIBRATE, for haptic feedback. BIND_INPUT_METHOD is the permission Android requires to offer a keyboard and does not grant Internet access.

There are no accounts, profiles, synchronization or account data on servers of Ethic Keyboard.

Your controls and changes

You can turn the keyboard off or clear its data in Android's Settings. If these practices change, this policy will be updated before the affected version is distributed, with the date and a description of the change.
